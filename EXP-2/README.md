# Experiment 2 – Train Booking UI Prototype

**Aim:** To design a user interface prototype for a mobile station using Figma, considering connectivity and convenience.

**Software Used:** Figma

**Screens Designed:**
1. Welcome Page
2. Login Page
3. Forgot Password
4. Create an Account
5. Train Booking Home
6. Select Your Train
7. Train Details
8. Seat Selection
9. Payment
10. Booking Successful

**Result:**
An interactive train booking user interface prototype was successfully designed using Figma.
